Forecast: NOAA/NCEP GEFS via the NOAA Open Data Dissemination programme (AWS). Basemap: Natural Earth. Colour schemes: ColorBrewer (RdYlBu, Blues, RdPu). Map engine: Leaflet.

The “L” markers are local pressure minima below the threshold shown in the legend. In the minimum product, each L is attributed to the member that supplies the lowest value there.
